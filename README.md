# Deutsch 90 — немецкий за 90 дней

Персональное веб-приложение (PWA) для изучения немецкого на русском языке. Его основа — курс «Немецкий язык с нуля до C1»: 50 уроков, фразы, тесты и разговорный курс. Материалы переведены с украинского, а видео не используются.

## Что внутри

- **Тест уровня.** Адаптивный, 6 блоков от A0 до B2. По результату определяется, с какого урока начать.
- **Личный план на 90 дней.** Он строится по стартовому уроку и времени в день (30 / 45 / 60 / 90 минут). Каждый день содержит конкретные задания. Каждый 7-й день отведён повторению, 90-й — итоговый.
- **50 уроков грамматики.** В каждом уроке: теория с таблицами, советы, примеры, словарь, фразы курса для проговаривания и 18–20 упражнений четырёх типов (выбор, пропуск, перевод, порядок слов).
- **Фразы.** Тренажёр по методу курса: видишь русскую фразу, говоришь или пишешь её по-немецки и сверяешься с ответом. Есть озвучка.
- **Карточки слов.** Около 1100 слов из уроков, интервальное повторение 1 → 3 → 7 → 14 → 30 → 60 дней.
- **5 контрольных тестов курса:** Белый, Жёлтый, Оранжевый, Зелёный и Чёрный, всего 290 заданий.
- **Справочники и разговорный курс:** неправильные глаголы (73), управление глаголов (93), разговорный курс (15 тем: bei, nach, doch, wohl, knapp…).
- **Озвучка.** Немецкий текст произносит браузер (Web Speech API). Скорость озвучки настраивается.
- **Офлайн-режим и установка на телефон** («Добавить на главный экран»).

Прогресс хранится в `localStorage` браузера. В разделе «Ещё» можно скачать резервную копию и загрузить её на другом устройстве.

## Запуск

Приложение статическое, сборка не нужна:

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

Деплой на GitHub Pages выполняет `.github/workflows/pages.yml` при пуше в `main`.

## Структура

```text
index.html, css/app.css      оболочка и дизайн (светлая/тёмная тема)
js/app.js                    роутер (hash)
js/views.js                  все экраны
js/plan.js                   генератор плана на 90 дней
js/quiz.js                   движок упражнений и проверка ответов
js/srs.js                    интервальное повторение слов
js/store.js                  прогресс (localStorage, экспорт/импорт)
content/placement.json       тест уровня
content/lessons/NN.json      уроки 1–50
content/extra/*.json         тесты, глаголы, управление, разговорный курс
```

Формат урока: `id, title, level, goal, minutes, theory[{h, html}], tips[], examples[{de, ru}], vocab[{de, pl, forms, ru}], phrasesNote, phrases[{de, ru}], exercises[]`.
